# Definition of Done

- [ ] Scope 與 Acceptance Criteria 全部通過。
- [ ] Exact Files 以外沒有未說明修改。
- [ ] Required Commands 全部成功並保存 machine-readable evidence。
- [ ] Happy/boundary/error/cancel/cleanup tests 完整。
- [ ] Architecture/format/lint/build/test gates 通過，無新增 warning。
- [ ] Error/timeout/disconnect/cancel/sleep/termination 路徑有 cleanup。
- [ ] Logs/diagnostics 無 typed text、clipboard payload、secret/key material。
- [ ] C/S/H 指定 review/evidence 已完成。
- [ ] PR 逐條對照 AC、列出 known limitations、rollback、follow-up。
- [ ] Reviewer 能只依 Issue 與 evidence 重現判斷。
