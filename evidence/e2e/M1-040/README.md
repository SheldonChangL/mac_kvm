# M1-040 E2E Evidence

`result.json` is generated by `Tests/SystemTests/Scripts/M1-040-barrier-keyboard-fixtures.sh` through `Tools/Evidence/run_e2e.py`. It validates the sanitized Barrier keyboard fixture and the M1-040 evidence package locally.

The script never opens a network connection and never repeats capture. It reads repository files, recomputes fixture digests, checks privacy/non-claim constraints and writes `result.json` atomically through the e2e runner.

## Rerun

```bash
make e2e ISSUE=M1-040
python3 Tools/Evidence/validate_evidence.py evidence/e2e/M1-040/result.json
```

The generated timestamps and commit follow the run; fixture bytes remain deterministic.

## Review status

`result.json` marks the fixture artifacts as `reviewed` in the narrow sanitizer-producer sense required by `Tools/Evidence/validate_evidence.py`: the retained repository artifacts were checked for format, digest, privacy and non-claims before being used as E2E evidence. This is not the independent M1-040 review gate. `evidence/issues/M1-040/independent-review.md` is the separate non-implementing reviewer record required before merge.
